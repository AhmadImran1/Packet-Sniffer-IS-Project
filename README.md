->Packet Sniffer for Network Traffic Monitoring

-Overview-
This project aims to develop a packet sniffer to capture and monitor network traffic in real time. The tool will display crucial details about each network packet, such as:
.Source and destination IP addresses
.Ports and protocols (TCP, UDP)
.Data size
.HTTP request types (GET, POST) and their associated URLs
This tool is designed to help users gain visibility into their network traffic and detect unusual activities, enhancing their understanding of web traffic and data flow anomalies.

-Features-
.Real-Time Packet Capture: Monitor live network traffic as it happens.
.Detailed Packet Information: Display details such as IP addresses, ports, and protocols.
.HTTP Analysis: Identify HTTP request types (GET, POST) and their URLs.
.Traffic Filtering: Filter captured traffic based on protocols (TCP, HTTP) or specific IP addresses.

-Objectives-
.Capture and display network packets in real-time.
.Provide a detailed breakdown of packet information.
.Enable filtering for targeted analysis of network traffic.
.Support HTTP request identification for deeper insights into web traffic.

-Expected Outcomes-
.A functional tool for network traffic monitoring.
.Capability to filter and analyze specific packets, including HTTP requests.
.Improved visibility into potential anomalies within network data flow.
